# ✨ Templates

This section showcases all the available portfolio templates for easier navigation and understanding. Some templates also support **themes** (color/style variations), which are detailed here.

All templates and themes are fully **responsive** and support both **🌞 light mode** and **🌙 dark mode** for optimal viewing on any device.

Explore the template folders via the links provided, and view live demos, snapshots, and complete source code.

---

## 🧊 Minimalist Professional: Elegant Portfolio Framework [`Minimalist_Professional`](Minimalist_Professional)

A clean and professional portfolio template with neutral colors, simple layouts, and readable typography. It includes **four themes**, each with its own color accents and styling.

🎨 **Color Palette** (see [`css/variables.css`](Minimalist_Professional/css/variables.css)):

- `--soft-grey`: `#f4f4f4` – Light grey background
- `--mid-grey`: `#dcdcdc` – Adds structure and contrast
- `--accent-coral`: `#ff6f61` – Coral accent for highlights
- `--accent-green`: `#2e8b57` – Green accent for headings or links
- `--primary-text`: `#222222` – Main text color
- `--secondary-text`: `#555555` – Secondary text color
- `--background`: `#ffffff` – White background
- `--link-hover`: `#003366` – Link hover color

🧩 **Typography:** `'Segoe UI'`, system UI, sans-serif

📐 **Design:** Responsive grid layout with modular CSS that's easy to customize
